# すうがくの森

算数の問題をとくと、森の なかまの「おねがい」がかなって、どうぐが育ち、家具がつくれて、キャンプが にぎやかになる。小学生（小1〜小6）向けのゲーム。

数学ラボ（バトル・RPG）とは別のソフト。数学ラボが「挑む・強くなる」なら、こちらは「暮らす・つながる」算数。

> いまは **試作**。遊びの流れはひととおり動くが、見た目は絵文字の仮置き。
> デザインは Codex に依頼する → [docs/DESIGN_BRIEF.md](docs/DESIGN_BRIEF.md)

## 遊びの流れ（1日10分）

| | すること | 算数 |
|---|---|---|
| おねがい | 住人4人が、それぞれ1日3つ おねがいしてくる（さいごの1つは とくべつ⭐） | 住人の分野の問題（文章題が多い） |
| つり | うきが しずんだら、4択をすばやく（1回5ひき） | けいさんの筋トレ |
| つくる | 素材がそろったら「せっけいの もんだい」をといて家具をつくる | せっけいずの分野の問題 |
| キャンプ | つくった家具を 4×4 のますに おいてかざる。なかよしの住人が あそびにくる | — |
| たからのちず | まちがえた問題の「同じ型・数字ちがい」をといて、たからばこを あける | ふりかえり |

10問とくと「きょうの もくひょう たっせい！」。つづけてもいいし、キャンプを見ておわってもいい。

## 3つの約束

1. **算数を「通行料」にしない** — おねがい・せっけいず・つり、遊びの中で算数を使う。ごほうびのための問題ではなく、森で使う ことばとして。
2. **まちがえても、なにも へらない** — まちがいは「たからのちず」になり、あとで同じ型をとくと たからばこが ひらく。とけなくても住人は「ちょうせん ありがとう」。
3. **10分で「きょうは ここまで」** — 1日のもくひょう（はじめは10問）に とどいたら、おわりにしやすい声かけをする。

## 住人と分野

| 住人 | 分野（area） | 担当する単元の例 | お礼の素材 | どうぐ |
|---|---|---|---|---|
| ムギ（くま・くいしんぼう） | かず・けいさん（num） | たし算・九九・わり算・小数・分数 | まるた | かご |
| チクタ（りす・きっちりや） | とけい・はかる（func） | 時計・長さ・かさ・重さ・速さ・割合・比例 | いし | ものさし |
| ルル（うさぎ・おしゃれ） | かたち（geo） | 三角形・円・角・面積・体積・対称 | けいと | コンパス |
| メモ（ねこ・しらべものずき） | しらべる（data） | 表とグラフ・平均・場合の数 | はな | むしめがね |

1年生には「しらべる」の単元がないので、メモは「2ねんせいに なったら くる」。名前・せいかくは仮。

## 問題はどこから来ているか

- **数学ラボ ソロ**（math-dialogue の `src/solo`）の小学校の問題テンプレートを、そのまま使っている。小1〜小6・55単元・951テンプレート。毎回数字が変わり、ヒント・とき方・4択の誤答（よくある間違い）・前提の単元がついている。
- `npm run sync` で `src/shared/` にコピーする。**`src/shared/` は直接編集しない**（問題を直すときは数学ラボ ソロの側を直してから sync）。
- 数学ラボ ソロは、いまは math-dialogue のブランチ **`claude/keen-tesla-em1r7j`** にある（main にはまだ入っていない）。どのコミットから同期したかは `src/shared/SOURCE.json`。
- 同期スクリプトは、`suugaku-no-mori` と `math-dialogue` が同じ親フォルダにある前提。ちがう場所なら `npm run sync -- --from <math-dialogue/src/solo の場所>`。

## 動かし方

Node.js（LTS）が必要。

```bash
npm install
npm run dev      # http://localhost:5185/
npm test         # ルールと問題のテスト（全テンプレートで「正解を入れると正解になる」も確かめる）
npm run build    # 公開用（dist/）
npm run sync     # 数学ラボ ソロから問題を取りこみなおす
```

- デザイン確認用：`http://localhost:5185/?demo`（素材・家具・なかよし・たからのちずが そろった状態。`?demo=E1` で1年生）。デモは ほんもののセーブとは別に保存される。
- 記録は端末のブラウザ（localStorage の `suugaku-no-mori:v1`）だけ。広告・課金・外部への送信はない。

## フォルダ構成

```
src/
├── App.jsx            … 画面のつなぎ役（うすく）
├── content/index.js   … ★出題の窓口：単元の一覧・1問つくる・同じ型でもう1問・4択にする・答え合わせ
├── shared/            … 【自動同期】数学ラボ ソロの小学校テンプレート（直接編集しない）
├── engine/            … ★ゲームの核（画面に依存しない純関数）
│   ├── pick.js          どの単元・レベルから出すか（学年・習った範囲・分野・2連続でレベル上下）
│   ├── game.js          ごほうび・なかよし・どうぐ・つくる・おく・たからのちず
│   ├── save.js          セーブの形と読み書き（サーバー保存にするときは ここを差しかえる）
│   └── demo.js          デザイン確認用のセーブ（?demo）
├── data/              … 住人（villagers.js）・素材/どうぐ/家具（items.js）
├── ui/                … 共通部品（Art＝絵の差しかえ口、ProblemCard＝1問をとく部品、数字キー、数式表示、よみあげ）
├── screens/           … 画面（はじめに・もり・おねがい・つり・つくる・キャンプ・たからのちず・もちもの・せってい）
└── styles/            … 見た目（tokens.css＝色や大きさ、app.css）
scripts/sync-content.mjs … 問題の同期
test/                  … node:test（npm test）
docs/                  … 設計メモ・デザイン依頼書
```

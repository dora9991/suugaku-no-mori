# デザイン変更履歴

## 2026-10-16 — 森のなかで遊ぶ、すうがくの森

### コンセプト

「どのカードを押すか」から、「だれに会いにいくか・どこで遊ぶか」へ。朝の森、曲がる土の道、小さな池、木と布の道具を一枚のシーンにまとめました。住人に話しかけ、算数で手伝い、集まったものが自分のキャンプになる楽しさを、絵・動き・音で伝えます。

### 変更していないもの

- `src/shared/`・`src/engine/`・`src/content/`・`src/data/` はすべて差分ゼロです。問題の同期は実行していません。
- 出題、採点、問題数、残り回数、20秒の制限、ごほうび、なかよし、家具の必要素材、配置ルール、セーブの構造とキー `suugaku-no-mori:v1` はそのままです。
- 各画面の既存の `act` / `go` / engine の呼び出しを維持しています。追加した HUD のもちものショートカットも既存の `go("bag")` を呼びます。
- 学年・習った範囲・読み上げ・目標・データ削除の処理も維持しています。文言の追加はひらがな中心です。

### 全画面に共通する変更

- 色・文字・角丸・影・タップ寸法を `src/styles/tokens.css` に整理。生成りの紙、深い森の文字、はちみつ色、土と木の色を使用します。
- 本文は原則18px以上、問題は24〜26px、数字キーは28〜30px。ボタンは48px以上、主なボタンは56px以上です。
- OS の絵文字をオリジナルの SVG に置換。既存の `Art` の name と xs / sm / md / lg / xl の呼び出しは維持しました。
- 住人に通常・よろこぶ・こまる表情を追加し、通常時にまばたき・ゆれ、話しかけたときに軽いジャンプを表示します。
- 住人のせりふは短い文字送り。途中でタップすると全文が見え、次の操作のために演出を待つ必要はありません。支援技術には最初から全文を渡します。
- HUD にプレイヤーの絵、ひらめきの実、今日の目標ゲージ、もちもの、音、設定を配置。数値の更新には短いカウントアップを使います。
- 正解・家具完成・宝箱・なかよしアップ・どうぐアップ・目標達成に、短い文字のポップ、葉や紙吹雪、素材がかばんへ飛ぶ演出を追加。演出レイヤーは入力を遮りません。
- 不正解にはやさしい茶色の吹き出しと困った表情を使用。赤い×、画面の揺れ、大きなブザーはありません。
- 画面の切替は短いフェード、ボタンは押すと沈む反応。解答中は常時動く背景や BGM を抑え、問題・選択肢・数字キーを優先します。
- 通知は画面下側に寄せ、問題表示中は隠して解答を覆わないようにしました。
- 分数を KaTeX の `\displaystyle` で表示し、分子・分母の読める大きさを確保しました。選択肢の読み上げ用の名前は、既存の `toSpeech` を使って「3ぶんの2」のように付けます。問題・答えの値は変えません。
- フォーカスを太く表示し、目標達成ダイアログ内で Tab / Shift+Tab が巡回、Escape で閉じるようにしました。
- `prefers-reduced-motion` では CSS の動きを停止し、文字送り・カウントアップも最初から最終表示にします。

### 音

`src/ui/sound.js` に、正弦波・三角波による自作の効果音と五音を基調にした短い BGM を実装しました。タップ・正解・おしい・かかった・つれた・できた・レベルアップ・家具を置く音があります。森とキャンプは別のテンポと音域、問題の画面は BGM なしです。

初回は無音で、上の ON/OFF 操作で有効になります。保存するのは別の表示設定キー `suugaku-no-mori:sound:v1` のみです。再読み込みで ON を覚えていても、最初の操作まで音を出しません。タブを隠すと予約した音楽を止め、OFF や画面の切替でループが増えないようにしています。Web Audio やストレージが使えなくても遊びを妨げません。

### 素材の出どころ・再編集

- 絵はすべてこの実装で描いたオリジナルです。外部素材、既存ゲームのキャラクター・ロゴ・UI・音源は使用していません。
- `scripts/draw-art.mjs` が生成元。`node scripts/draw-art.mjs` で `public/art/` と favicon を再生成できます。
- 57点のアイコン・住人の表情と森の背景1枚、計58枚の SVG。合計約65KB、最大の森の背景も約19KBです。
- 外部画像、Webフォント、音声ファイル、新しい実行時ライブラリは追加していません。音もすべて Web Audio での自作合成です。
- 開発中だけ `?demo&look=night` からキャンプを開くと、昼間でも夜の絵を確認できます。公開版にはこの上書きは入らず、従来の18時以降の判定を使います。

- `npm run build`：**成功**。Vite の本番用ビルドを作成しました。

- たからのちず→似た問題→宝箱、なかまに魚を渡す→なかよしアップ、目標達成ポップアップを確認しました。

# すうがくの森 — 設計メモ（試作版）

## 1. ねらい

- 数学ラボは「挑む・強くなる」ゲーム。すうがくの森は「暮らす・つながる」ゲーム。戦うのが苦手な子の、もう一つの入口。
- 算数を **ごほうびのための通行料にしない**。住人のおねがい・家具のせっけい・つり、森でくらす中で算数を使う。
- **まちがいは たから**。まちがえた問題は「たからのちず」になり、同じ型（数字ちがい）をとくと たからばこが ひらく。
- **10分で「きょうは ここまで」**。もくひょう（はじめは10問）に とどいたら、気持ちよく おわれる声かけをする。

## 2. 1日の流れ

```
もり（ホーム）
 ├─ おねがい（住人4人 × 1日3つ。さいごは とくべつ⭐）… 住人の分野の問題 → 素材・なかよし・どうぐ
 ├─ つり（1回5ひき・4択・20びょう）              … けいさん → さかな・素材・ひらめきの み
 ├─ つくる（せっけいず10種）                      … せっけいの問題 → 家具
 ├─ キャンプ（4×4 にかざる）                      … なかよしの住人が あそびに来る
 ├─ たからのちず（まちがえた問題）                 … 同じ型をとく → たからばこ
 └─ もちもの／せってい
```

## 3. 出題のきまり（`src/engine/pick.js`）

- 出すのは **いまの学年まで** の、**習った** 単元（せっていで「まだ」にした単元は出さない）。
- 学年の重み：いまの学年 4、1つ下 2、それより前 1（前の学年は復習として少し）。
- 住人は自分の分野（area）から出す。その分野の単元が無いと「おでかけ中」（例：1年生にはデータの単元がないので、メモは2年生から）。
- つりは「かず・けいさん」の きほん（レベル1）を4択で。数の答えは `numChoices` でまわりの数から4択にする（分数の答えなど4択にできない問題は出さない）。
- 直近2つの単元と、直近12のテンプレートは なるべく避ける。

## 4. レベル（分野ごと）

- レベルは 1（きほん）〜3（ちょっと むずかしい）。**2回つづけて1回で正解** で上がり、**2回つづけて とけない** と下がる。
- 住人の その日さいごの おねがいは **とくべつ⭐**：いまのレベル＋1（4＝思考問題まで）。
- つりは いつもレベル1（動かさない）。

## 5. ごほうびの数字（`src/engine/game.js`）

| 場面 | 正解 | とけなかった |
|---|---|---|
| おねがい | 住人の素材 ×レベル（1回で・ヒントなし +1、とくべつ +1 と ひらめきの み）、なかよし +10（1回で・ヒントなし +5、とくべつ +10）、分野のどうぐ +1 | なかよし +2、たからのちずへ。なにも へらない |
| つり | ひらめきの み 20%／さかな 35%／素材 45%、どうぐ +1 | たからのちずへ（時間切れは なにもなし） |
| つくる | 素材を使って家具が1つ、どうぐ +1 | 素材は へらない。たからのちずへ |
| たからのちず | 素材3つ＋ひらめきの み、その分野の住人と なかよし +10 | ちずは のこる |

- **どうぐ**（分野ごと）：その分野で正解した数で レベル1→2→3→4→5（0・5・15・30・50問）。せっけいずは「どうぐのレベル」で ひらく。
- **なかよし**：20・50・90・140・200 ポイントで ハート1〜5。ハート1つ以上で キャンプに あそびに来る。好きな家具が置いてあると ♥。
- **ひらめきの み**：はじめに3つ。ヒント（`hint`）を1つ見ると1つ へる。とくべつ・つり・たからばこで ふえる。
- **たからのちず**：同じ型（テンプレート）は1枚にまとめる。30枚まで（古いものから消える）。

## 6. 問題データ（数学ラボ ソロから）

- `src/shared/elem/e1〜e6.js`：小1〜小6の単元（`id` `grade` `area` `name` `prereqs` `levels{1〜4: テンプレート[]}`）。
- テンプレートは `t(id, (r) => ({ q, ans, choices?, unit?, hint, steps }))`。`r(min,max)` を渡すと1問できる。
- 答え合わせは `src/shared/answer.js`（数学ラボ ソロと同じ。分数は約分まで）。すうがくの森では「約分していない」「数字でない」は回数を へらさず、やさしく言いなおす。
- 数字キーの「.」「/」は、答えの形ではなく学年で出す（小数・分数は3年から。2年は「分数のはじまり」の単元だけ）。キーで答えの形が ばれないように。
- `npm test` で、全テンプレートについて「問題が作れて、正解を入れると正解になる」ことを確かめている。

## 7. セーブ（`src/engine/save.js`）

ブラウザの localStorage（`suugaku-no-mori:v1`）。デモは `suugaku-no-mori:demo:学年`。

```js
{
  v, name, grade: "E1"〜"E6", unlearned: [単元id],
  settings: { fishTimer, speech, dailyGoal },
  day, today: { solved, correct, requests: { 住人: 回数 }, goalShown }, playDays,
  inv: { maruta, ishi, keito, hana, sakana, hirameki },
  furn: { 家具: 数 }, camp: [{ id, x, y }],
  friend: { 住人: ポイント }, tools: { 分野: 正解数 }, levels: { 分野: { L, up, down } },
  recent: { tpl: [], unit: [] }, treasure: [{ id, unitId, level, tplId, area, q, at }],
  stats: { solved, correct, treasureCleared, crafted, fish },
  log: [{ t, day, mode, unitId, level, tplId, ok, firstTry, hints, timeout }]   // 300件まで
}
```

`log` は、あとで保護者・先生向けの画面（どの単元でつまずいたか）に使う。

## 8. これから（アイデア）

- **見た目**：Codex に依頼（[DESIGN_BRIEF.md](DESIGN_BRIEF.md)）。
- **小学生に さわってもらう**：まず数人に遊んでもらい、ひらがなの読みやすさ・つりの時間・ごほうびの多さを見なおす。
- **住人を持ち寄れる形**：住人1人＝問題パック1つ。先生が「自分の授業の住人」を足せるようにすると、使われ・直され・持ち寄られて森が育つ。
- **つまずきから さかのぼる**：数学ラボ ソロの前提単元（`prereqs`）を使い、たからのちずが たまった単元の「前の単元」を住人がそっと出す。
- **図が要る問題**：時計の針を動かして答える、ますに図形をかく など（いまは文章で決まる問題だけ）。
- **保護者・先生の画面**：`log` から、単元ごとの正解率・つまずき・あそんだ日。
- **サーバー保存**：`save.js` の load / save を差しかえる（数学ラボと同じ考え方）。
